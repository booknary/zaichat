# ZaiChat 0.8.0-beta.46

## 简体中文

首次公开的最新版快照，仅发布当前版本，不上传之前的 XPI 或私人历史数据。

- 支持 Zotero 9–10.0；本次原生测试环境为 Zotero 10.0.6。
- 本地文库模糊搜索、语义召回、有界全文核查和可点击引用；支持 RSS 摘要问答。
- 会话历史、Markdown 导出、模型/思考强度切换、侧栏/独立窗口和显式上下文选择。
- 核查并补齐运行状态、阅读器上下文和连接测试结果的中英文显示；不改搜索提示词或排名。
- 中英文 README 含实际 Zotero 截图。截图使用合成文献和明确标注的预置对话，非实时模型输出。
- Windows x64 CPU worker 随包提供，用户无需安装 Python；模型单独下载并校验。
  Small 为推荐默认档，Base/Large 仍是未完成全部部署回归的测试选项。

安装：下载本页 **`zaichat-0.8.0-beta.46.xpi`**，在 Zotero 的插件管理器中从文件安装。
不要把 GitHub 自动生成的源码 ZIP 当成安装包。请自行配置 API 服务和密钥。
现有用户不需要重建向量索引，配置及会话不会随升级清空。

安全：安装包不含私人 API Key、会话、向量索引或模型权重；远程对话服务会收到所需问题和
有界证据，密钥保存在 Zotero 偏好中，并非系统加密密钥库。仅笔记/标签/Related 写入需要审批。
不含自动分类或 Collection 重组，不提供 GPU/macOS/Linux 本地向量运行环境。

验证：333 项单元测试通过（另有 1 项既有可选测试跳过）；26 项 Zotero 隔离检查通过，
其中截图停留测试在普通运行中不启用，其他环境门控的模型/网络探针也不是全部执行。
类型检查、lint 和生产构建通过。回答仍需核实，引用校验不是科学事实核查。

## English

First public snapshot of the current version only—no previous XPIs or private
development/conversation history are uploaded.

- Zotero 9–10.0 compatibility; native validation on Zotero 10.0.6.
- Local-library lexical/semantic retrieval, bounded fulltext verification,
  actionable citations, RSS abstract questions, and explicit context attachment.
- Conversation history/export, model/effort controls, sidebar/standalone window.
- Completed bilingual presentation for statuses, reader context and connection
  checks without changing prompts, ranking, embeddings or index format.
- English/Chinese READMEs include real Zotero screenshots using synthetic data
  and explicitly prewritten demo responses—not live model output.
- Bundled Windows x64 CPU worker; no Python/server startup required for users.
  Model weights download separately with verification. Start with Small;
  Base/Large remain experimental and have not completed full deployment regression.

Install **`zaichat-0.8.0-beta.46.xpi`** using Zotero's Install Plugin From File action.
The auto-generated source ZIP is not an installable plugin. Configure your own
provider/key. Existing users need no reindex; upgrade does not clear conversations.

No private API keys, conversations, indexes or model weights are packaged. Your
configured provider receives relevant questions and bounded evidence; keys reside
in Zotero preferences, not an OS keychain. Note/tag/Related writes require approval.
No automatic collection classification/reorganization, GPU mode or macOS/Linux
semantic runtime is included.

Validation: 333 unit tests passed, one existing optional test skipped; 26 isolated
Zotero checks passed (documentation capture is opt-in; environment-gated external
model/network probes are not all exercised), plus type checking, lint and
production build. Citation checks do not guarantee scientific correctness.

See [English README](https://github.com/booknary/zaichat#readme) and
[中文说明](https://github.com/booknary/zaichat/blob/main/README.zh-CN.md).
The `.sha256` asset provides the installable package checksum. Updates are manual.
