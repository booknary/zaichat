# ZaiChat 0.8.0-beta.51 / Beta prerelease

发布日期 / Release date: 2026-11-05.

这是 beta 测试版；旧版 Release 和安装包保留。Zotero 9–10.0，原生验证环境为 Zotero 10.0.6；捆绑语义运行环境仅支持 Windows x64 CPU。

- 引导模式、已保存配置、模型和思考强度改为聊天文档内的菜单，避免 Zotero 原生下拉弹层重复绘制。展开菜单约束在聊天区域内；支持方向键、Enter、Esc、外部点击关闭和模型搜索。
- 编辑并重试使用聊天窗口内的编辑框，避免调用主窗口 prompt 导致独立窗口退到后面。不使用强制置顶或循环抢焦点；其他原生提示归属当前聊天文档。
- 历史列表增加两行标题、更新时间、行间距及独立删除按钮。统一输入、弹窗、菜单和工具栏间距；关闭按钮使用单字符图标。手动模型输入和高级兼容设置折叠显示。
- 设置页新增“设为默认”；首次保存自动建立默认配置，之后保存其他配置不再更改默认项。聊天内临时切换与“下次启动默认使用此平台和模型”分开，保留原有默认配置。
- 重启时从现有索引按文库 ID 与文献键去重恢复文献计数，区分文献数与向量数；增量增删同步更新。完成状态显示“已索引 N 篇文献”，构建中的状态保留进度分母。无需重建索引。
- 已通过后续校验的引用／答案修复显示“已完成（回答校验已修复）”；真正的工具异常和未修复校验仍显示警告，原始事件保留。
- 修复章节识别将参考文献之后的扩展图注、报告清单等持续误标为参考文献的问题。仅明确的章节／图表标题终止前一节；未知清单保留 unknown，不自动认证为方法；真正参考文献仍不能充当方法执行证据。

本轮 UI 与状态修复未调整检索排序、召回数量、上下文／证据预算或索引模型。百炼供应商前缀不做自动剥离。

安装：Zotero → 工具 → 插件 → 从文件安装，选择 releases/zaichat-0.8.0-beta.51.xpi，按提示重启。未自动安装到个人 Zotero。已有会话不改写；重试可应用新的章节识别规则。

## 自上一公开版 beta.46 以来

- 新增 DeepSeek 官方、火山方舟、阿里云百炼、OpenAI 官方的平台配置，独立保存端点、密钥、模型及兼容参数；加入 OpenAI Responses 支持。
- 修复 DeepSeek 工具历史中的空 reasoning_content 兼容问题。连接测试区分基本 API、思考和工具往返，未知服务不再自动携带专有思考参数。
- 运行中支持引导当前任务、排队下一条消息和澄清回复，保留输入草稿。
- 改善引用 ID 解析、局部回答修复、结论范围限定、作者完整性及候选预览。保持已有检索排序与预算。

## English

This beta improves same-document menus, in-window edit/retry, readable conversation history, explicit default provider profiles, restored semantic-index paper counts, and completion messages that distinguish repaired answer validation from real tool failures. Explicit captions and reporting headings now end bibliography provenance instead of inheriting it indefinitely. Unknown sections remain conservative; bibliography mentions still cannot prove method execution.

Since public beta.46, the release also adds platform profiles for official DeepSeek, Volcano Ark, Alibaba Cloud Bailian and OpenAI, Responses support, thinking/tool-protocol compatibility fixes, steering/queue/clarification interactions, and evidence/citation/author completeness improvements.

Install the XPI through Zotero Tools → Plugins → Install Plugin From File, then restart if requested. Existing semantic indexes do not need rebuilding for this update. Existing saved conversations are not rewritten; rerun to apply new evidence classification.

## 验证 / Validation

- 448 unit tests passed; one pre-existing optional startup test skipped.
- 35 isolated Zotero native checks passed, including expanded long-name menus and detached-window editing.
- TypeScript, formatting/lint and production build passed. Optional network/download probes remain gated.
- No bundled API keys, personal conversations, indexes or model weights. The XPI SHA-256 is 440dfab3812a6a5fe0ef63e7007b240e9d1ddf01a7a4a38d3d63b654e9042cda.

Platform adapters are not certification of every model/account/region; live provider credentials were not used in this validation. Native acceptance has mainly involved biology; cross-disciplinary accuracy is not established. Citation/quote guards do not constitute a scientific fact checker. Base/Large semantic models remain experimental, and macOS/Linux semantic deployment and GPU mode are not supported. Updates remain manual.
