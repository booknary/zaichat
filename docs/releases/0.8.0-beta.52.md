# ZaiChat 0.8.0-beta.52

发布日期：2026-11-09。Beta 预发布；旧版 Release 与安装包保留。

## 修改

- 回答校验区分缺失正文、缺失附件清单、引用文字不匹配和修复参数错误。返回可执行的补读参数；恢复提示在后续模型请求中保留。已有草稿可仅更新来源或事实后重新校验，完成的草稿不跨轮复用。
- 增加 candidateOnly 候选输出：无法完成核验时，程序生成最多五篇待核实候选和明确限制，不接受模型随附的未经核实结论。
- 漏检追问使用已保存的检索轨迹，区分排名、候选投递和已读证据。诊断缺失时保持未知；候选已展示不等于已阅读全文。历史片段带阅读时间保留，旧引用 ID 不作为当前来源重新使用。
- 对“只用于、纯属、不在补充材料”等排他性方法结论增加局部范围检查；末尾统一免责声明不能替代对具体结论的限定。此检查是有限语言规则，不是自动科学事实核验。
- 图注标签遇到后续不明小标题或远距离正文时降为未知，避免图注分类长期延续。明确的方法标题仍可恢复方法分类。
- 同篇题录引用可以与当前正文证据一起使用；只有题录时仍需补读。多个候选之间的“这篇”优先澄清；正文减少内部编号、缓存长度及重复审计信息，保留影响结论的限制。

## 安装与边界

在 Zotero 插件管理中选择 releases/zaichat-0.8.0-beta.52.xpi，按提示重启。旧安装包保留；不自动安装到个人配置。原有会话不会改写，重新提问或重试才应用新的回答流程。

检索排序、召回参数、上下文及证据预算、语义模型和索引格式未调整，无需重建索引。未增加依赖。未调用个人 API Key 进行付费模型测试，也未改写个人文库。

检索回顾依赖会话中已保存的诊断记录；旧会话无记录时不能追溯排名。历史片段只提供上下文，新结论仍使用本轮证据。规则与模拟测试不能保证所有平台模型都正确执行恢复指引，仍需观察真实新会话。

## English

Beta prerelease dated 2026-11-09. Previous releases and installers remain available. This update adds actionable evidence recovery, a program-generated unverified-candidate fallback, recorded retrieval history for retrospective questions, dated historical excerpts, bounded exclusive-purpose checks, and conservative caption boundaries. Ranking and all retrieval/context/evidence budgets remain unchanged. No private conversations or credentials are included.
